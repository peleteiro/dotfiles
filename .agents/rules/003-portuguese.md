# Idioma: Português (pt-BR)

## Comunicação

- Responda ao usuário em **Português do Brasil** (a menos que ele escreva em
  outro idioma).

## Commits

- Mensagens de commit em Português.
- Use Conventional Commits com emoji, seguindo o histórico do repo:
  `✨ feat:`, `🐛 fix:`, `♻️ refactor:`, `🔧 chore:`, `📚 docs:`, `✅ test:`.

## Documentação

- Arquivos Markdown internos (AGENTS.md, docs de dev) em Português.
- Exceção: `README.md` e `CLAUDE.md` podem ser em Inglês (são a porta de
  entrada pública do projeto).

## Comentários no Código

- Comentários técnicos em shell scripts podem ficar em Inglês para manter a
  consistência com o código já existente em `bin/` e `home/.bin/`.
